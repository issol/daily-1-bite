## Siri AI — 무엇이 진짜 바뀌나

이번 발표의 슈퍼스타. 기존 Siri는 "한 번 묻고 한 번 답하는" 음성 검색에 가까웠는데, Siri AI는 **컨텍스트 추적 + 화면 인식 + 앱 교차 검색**을 같이 합니다.

### 1. 화면 인식 (on-screen awareness)

지금 보고 있는 앱 화면을 그대로 인식해서 — 예를 들어 친구가 보낸 약속 메시지를 보면서 **"이 시간에 캘린더에 일정 잡아줘"** 한 문장으로 처리. 이건 GPT-4o의 Computer Use·[Claude Opus 4.8(5/31 글)](https://daily1bite.com/ko/blog/ai-tools/claude-opus-4-8-review-coding-honesty-fast-mode-2026)의 Online-Mind2Web 84%와 같은 방향이지만, Apple은 **OS 레벨 권한**으로 들어옵니다.

### 2. 앱 교차 컨텍스트

Messages·Mail·Photos·Calendar에 흩어진 정보를 Siri가 **하나의 답변으로 묶어줍니다**. 예: "지난 주말 친구가 보낸 식당 정보가 뭐였지?" → Messages에서 식당명 추출 + Maps에서 위치 + Photos에서 그 자리에서 찍은 사진 결합.

### 3. 웹 통합

기존 Siri의 가장 큰 약점이 "웹 검색은 못 한다"였는데, Siri AI는 웹 통합. 정확한 검색 엔진 정체는 공개 안 했지만, [5/12 Qualcomm·OpenAI·Meta 협업 글](https://daily1bite.com/ko/blog/ai/qualcomm-openai-meta-ai-wearables-replace-smartphones-2026)에서 짚었던 Apple-OpenAI 파트너십이 ChatGPT 폴백 형태로 들어올 가능성이 가장 높음.

### 4. 전용 Siri 앱

처음으로 Siri가 **별도 앱**으로 분리됐습니다. 이전 대화를 다시 열어 후속 질문, iCloud 동기화로 iPhone↔iPad↔Mac 사이 대화 이력 공유. 이건 ChatGPT 앱 UX를 거의 그대로 옮긴 형태.

## Apple Intelligence 2세대 — 사용자 손에 닿는 기능 6가지

### Spatial Reframing (Photos)

사진을 찍은 뒤에 **구도를 다시 짤 수 있는 기능**. AI가 원본 너머의 영역을 추론해서 채워줍니다. 인스타그램 크롭과 다른 점은 — **확장도 가능**. 살짝 잘려나간 인물 머리를 복원하는 식.

### Safari "Notify Me"

지금까지의 페이지 변경 알림 서비스(예: Visualping)를 OS가 직접 합니다. 예: "이 콘서트 페이지가 매진 풀리면 알려줘" → 백그라운드 모니터링.

### Messages 원탭 액션

대화를 분석해서 **리마인더/메모를 자동 제안**. "내일 3시 약속" 패턴을 감지하면 리마인더 등록 버튼이 자동 표시.

### Image Playground 업그레이드

이미지 생성 도구가 **새 스타일·새 모델**로 업데이트. 자세한 사양은 미공개지만, Apple Foundation Models v2가 비전 학습을 추가했다는 점에서 품질 도약 예상.

### Apple Watch 동적 그리드 + Smart Stack

워치 앱 아이콘이 사용 패턴에 따라 동적으로 재배치. AI가 시간대·위치·자주 쓰는 앱을 학습.

### Vision Pro Panorama-to-Spatial

기존 파노라마 사진을 **공간 장면(spatial scene)**으로 변환. Vision Pro 사용자만 해당이지만, 사진 라이브러리 가치가 한 번에 달라집니다.

## Apple Foundation Models v2 — 개발자에게 무엇이 열리나

핵심 발표지만 Apple답게 **세부 사양은 비공개**입니다. 공개된 내용을 정리하면:

| 항목 | v1 (2024) | **v2 (2026)** |
|------|-----------|----------------|
| 모달리티 | 텍스트 | **텍스트 + 음성 + 이미지** |
| 추론 위치 | 디바이스 + Private Cloud Compute | 동일 (PCC 강화) |
| 외부 모델 폴백 | ChatGPT (선택형) | 미공개 (확장 가능성) |
| 사이즈 | 미공개 | 미공개 (디바이스 모델은 더 작아진 듯) |
| 개발자 API | 제한적 | 확장 (Siri Kit, App Intents 통합) |

[Claude Fable 5(6/10 글)](https://daily1bite.com/ko/blog/ai-tools/claude-fable-5-mythos-class-public-release-2026) 발표 후 Anthropic이 모델 사이즈·벤치마크를 다 까는 흐름과 정반대 — Apple은 **개발자가 어떤 결과를 만들 수 있나**에 초점. 사이즈를 안 알리는 게 의도된 마케팅 전략입니다.

### 개발자 입장에서 챙길 점

- **App Intents 통합 강화**: Siri AI가 앱 안 액션을 부르는 표준 인터페이스
- **Spatial Reframing API**: 사진 앱이 아닌 서드파티도 사용 가능
- **음성 인식 v2**: 한국어 포함 다중 언어 동시 인식

WWDC26 세션 영상이 6월 8일부터 Apple Developer 앱에서 차례로 공개됐으니, iOS 개발자라면 다음 주 안에 핵심 5~6개 세션은 봐 두는 게 좋습니다.

## 성능 개선 — 숫자로 본 OS 업그레이드

Apple이 키노트에서 가장 강조한 수치들:

| 항목 | 개선 |
|------|------|
| 앱 실행 | **30% 빠름** |
| 사진 로딩 | **70% 빠름** |
| AirDrop 전송 | **80% 빠름** |
| iPad 파일 전송 | **5배** |

이 숫자들이 단순 최적화가 아니라 **온디바이스 AI 추론 비용을 부담하기 위한 인프라 정비**라는 게 진짜 포인트. AI 응답 속도가 빠르려면 OS 자체 응답이 먼저 빨라야 하니까요.

## 강점 / 약점 — 솔직한 평가

### 강점

- **한국어 1차 지원**: GPT/Gemini에 한국어가 늦게 들어왔던 것과 비교하면 큰 진전
- **OS 레벨 통합**: 앱 간 컨텍스트는 외부 LLM이 흉내내기 어려운 영역
- **프라이버시 우위**: 디바이스 + Private Cloud Compute 조합, 학습 데이터 보호
- **성능 개선 동반**: AI만 발표하지 않고 OS 전반 성능 정비

### 약점

- **늦었다**: Apple Intelligence 1세대(2024)가 약속 대비 한참 못 미쳤던 기억이 여전. 2세대 신뢰가 누적될 시간이 필요
- **모델 비공개 정책**: 벤치마크 없이 발표 — 개발자가 객관 비교 어려움
- **EU·중국 제한**: 글로벌 출시가 처음부터 일관되지 않음
- **기기 의존도**: iPhone 15 Pro/Pro Max 이상만 풀 기능. 일반 iPhone 15 사용자는 부분 기능만

## 한국 사용자가 챙겨야 할 5가지

### 1. 한국어 출시 1차 포함

영어와 함께 1차 지원. 베타 단계에서 번역·받아쓰기·요약 모두 한국어 정확도 테스트해 볼 만함.

### 2. iPhone 15 Pro 이상 사용자만 풀 기능

이게 한국에서 가장 큰 진입 장벽일 수 있습니다. iPhone 14·일반 15 사용자는 OS 업그레이드만 받고 Siri AI 풀 기능은 안 됨.

### 3. macOS Golden Gate — Mac 사용자 큰 변화

iOS만 보지 말고 macOS 27도 챙기세요. Mac에서 Siri AI 직접 호출, 앱 교차 컨텍스트는 데스크톱 워크플로 변동 큼.

### 4. 7월 퍼블릭 베타 — 일반 사용자 진입로

개발자 베타가 부담스러우면 7월 beta.apple.com 등록 후 퍼블릭 베타 받기. 기기 분리 안 해도 됨(단, 백업 필수).

### 5. 가을 정식 — 신형 iPhone 17 동시 발표 예고

전통적으로 9월 iPhone 17이 출시되면 새 OS도 함께 정식 배포. 새 기기 + AI 풀 기능 조합이 마케팅 핵심.
