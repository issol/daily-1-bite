**TL;DR — 한 문장 모순으로 시작합니다**

Anthropic은 6월 초 "AI가 점점 너무 위험해진다"는 공개 경고를 냈고, **그 며칠 뒤 자기들이 만든 가장 강한 모델을 일반에 풀었습니다**. 그 모델이 **Claude Fable 5**, [4월 27일 정리 글](https://daily1bite.com/ko/blog/ai-tools/claude-mythos-preview-anthropic-glasswing-2026)에서 봤던 **Mythos 클래스의 첫 공개 버전**입니다. 출시일은 **2026년 6월 9일**, 가격은 **$10/$50 per 1M** ([Anthropic 공식](https://www.anthropic.com/news/claude-fable-5-mythos-5)).

[TechCrunch가 정확히 지적한 모순](https://techcrunch.com/2026/06/09/anthropic-released-claude-fable-5-its-most-powerful-model-publicly-days-after-warning-ai-is-getting-too-dangerous/)인데, Anthropic은 이걸 의도된 트레이드오프라 부릅니다 — **"가장 위험한 5%는 막고, 나머지 95%는 풀자"**. 그 5%가 정확히 사이버공격·생물/화학 무기·모델 증류(distillation) 영역이고, 거기 닿는 세션은 자동으로 [Opus 4.8(5/31 글)](https://daily1bite.com/ko/blog/ai-tools/claude-opus-4-8-review-coding-honesty-fast-mode-2026)로 떨어집니다.

## "왜 지금 풀었나" — Mythos 사이클로 본 결정

4/27 [Mythos Preview 글](https://daily1bite.com/ko/blog/ai-tools/claude-mythos-preview-anthropic-glasswing-2026)에서 짚었던 의문이 **"이걸 일반 공개 안 하나?"** 였습니다. 그땐 Project Glasswing(미국 정부 사이버방어 협업)에만 한정. 한 달 반 만에 답이 나왔습니다 — **이중 채널 출시**.

| 채널 | 모델 | 대상 | 안전장치 |
|------|------|------|---------|
| **Fable 5** | Mythos 5와 같은 베이스 | 일반 (Pro/Max/Team/Enterprise) | 3개 카테고리 필터 켜짐 → Opus 4.8 폴백 |
| **Mythos 5** | 같은 베이스 | Mythos Preview 사용자 자동 업그레이드 | 사이버보안 필터 해제 |
| **Mythos 5 + Biology Trusted Access** | 같은 베이스 | 승인된 생물학 연구자 | 생물/화학 필터까지 해제 |
| **Mythos Preview** | 이전 세대 | 4/27 출시분 | 사이버 한정 액세스 |

읽는 방식이 두 가지 가능한데, 저는 이렇게 봅니다 — **공개 모델 시장에서 GPT-5.5와의 격차를 좁히는 동시에, 가장 민감한 영역만 별도 트랙으로 분리하는 다층 전략**.

[6/2 Anthropic $65B 글](https://daily1bite.com/ko/blog/ai/anthropic-965b-series-h-ai-consolidation-may-2026)에서 본 자본 사이클과도 직결됩니다. $965B 가치평가 + 10월 IPO 윈도우 + S-1 비공개 신청까지 — **공개 모델로 매출을 끌어올리는 시점**입니다.

## 어떤 문제를 어떻게 풀었나 — Stripe 사례 한 단락

Anthropic이 발표문에 직접 박은 사례가 충격적입니다.

> **Stripe**가 Fable 5로 **5,000만 줄 Ruby 코드베이스 마이그레이션**을 **단 하루**에 완료했다. 사람 팀이었으면 **두 달 이상** 걸릴 작업.

저는 처음 이 숫자를 보고 "보도자료 과장" 의심부터 했습니다. 하지만 [The Decoder의 검증](https://the-decoder.com/anthropic-releases-claude-fable-5-and-mythos-5-with-major-gains-in-coding-and-science/)에 따르면 Stripe가 직접 확인한 케이스, **"긴 컨텍스트 + 단일 패스 마이그레이션"**이 핵심.

Fable 5의 진짜 차별점이 여기서 드러납니다:

- **긴 작업일수록 격차가 커진다** — 짧은 코드 생성은 GPT-5.5나 Opus 4.8도 비슷한데, **수십만 줄을 한 호흡에 처리하는 능력**에서 Fable 5가 두드러집니다
- **컨텍스트 유지 + 도구 사용 일관성** — 수십 개 파일을 동시 수정하면서 의존성 흐트러지지 않게 처리

[5/31 Opus 4.8 글](https://daily1bite.com/ko/blog/ai-tools/claude-opus-4-8-review-coding-honesty-fast-mode-2026)에서 봤던 "코드 결함 4배 덜 숨김"이 Fable 5에선 한 단계 더 강해진 셈입니다.

## Before/After — 같은 마이그레이션을 두 가지 방식으로

가상 시나리오지만 익숙한 패턴입니다. 50만 줄짜리 모놀리식 Ruby 앱을 마이크로서비스로 쪼개는 작업.

### Before (Opus 4.8 사용 시 — 5/31 발행 기준)

```bash
# 1단계: 도메인 경계 분석 (1주)
claude --model claude-opus-4-8 \
  --task "Analyze domain boundaries" \
  --output domain-map.md

# 2단계: 서비스별 추출 (각 서비스 2~3일 × 12개 = 36일)
for service in $(cat services.txt); do
  claude --model claude-opus-4-8 \
    --task "Extract $service to standalone service" \
    --review-interval 2h
done

# 3단계: 통합 테스트 (2주)
# 사람이 직접 의존성·인터페이스 검증
```

총 작업 시간: **약 8~10주** (사람 + Opus 4.8 협업).

### After (Fable 5 사용 시 — 6/9 출시 기준)

```bash
# 1단계: 전체 마이그레이션 한 호흡에 발사
claude --model claude-fable-5 \
  --task "Migrate monolith to microservices with these boundaries: $(cat boundaries.txt)" \
  --max-tokens 200000 \
  --tools git,filesystem,test-runner \
  --auto-checkpoint

# 2단계: 사람 검수 (3~5일)
# Fable 5가 만든 PR 12개 검토 + 통합 테스트
```

총 작업 시간: **약 1~2주**. Stripe의 "두 달이 하루"는 극단적 케이스지만, **70~80% 단축은 일관되게 보고**되고 있습니다.

## 안전장치 3가지 — 세부

Anthropic 공식 발표에 따르면 **세 개의 분류기 카테고리**가 자동 폴백 트리거입니다.

| 카테고리 | 차단 예시 | 폴백 모델 |
|---------|-----------|----------|
| **사이버보안** | 익스플로잇 작성, 공격적 침투 기법, ZeroDay 발견 시도 | Opus 4.8 |
| **생물·화학** | 유전자 치료 설계, 바이러스 엔지니어링, 무기 전구체 합성 | Opus 4.8 |
| **모델 증류(distillation)** | Fable 5로 다른 모델을 무단 훈련시키려는 요청 | Opus 4.8 |

핵심 수치 — **"세션의 5% 미만에서만 폴백이 발생"** (공식 발표 verbatim). 즉 일반 코딩·지식 작업·과학 분석 등 **95% 시나리오는 Fable 5가 끝까지 처리**.

### 그 5%가 의미하는 것

표면적으로는 "거의 안 막힘"이지만, **막히는 경우 누가 막히나**가 진짜 신호입니다.

- 사이버보안 연구자 → Mythos 5 트러스티드 액세스로 별도 신청 필요
- 생물학 연구자 → Biology Trusted Access (별도 승인)
- 일반 개발자 → 안 막히는 게 정상 (단, Penetration testing 도구 작성은 자주 막힐 가능성)

저는 펜테스팅 도구 데모를 만들다 Opus 4.8로 떨어지는 걸 한 번 경험했습니다. 답변은 나오지만 **"Fable 5의 깊이"가 사라진 느낌** — Opus 4.8도 강하지만 긴 컨텍스트 일관성이 Fable 5보다 떨어집니다.

## 가격 — 짧은 무료 창 + 그 이후

| 구간 | 가격 | 비고 |
|------|------|------|
| 6/9 ~ 6/22 | **무료 포함** | Pro·Max·Team·Enterprise seat 기반 플랜 |
| 6/23 이후 | **사용량 크레딧** | 플랜 표준 복귀, 용량 따라 점진 복원 |
| API | **$10 in / $50 out per 1M** | Mythos Preview 대비 **절반 이하** |

[Opus 4.8 가격](https://daily1bite.com/ko/blog/ai-tools/claude-opus-4-8-review-coding-honesty-fast-mode-2026)이 $5/$25라서, **Fable 5는 정확히 2배**. Mythos Preview는 더 비싸서 일부 기관만 접근 가능했는데, **절반 가격으로 일반에 풀린 게 이번 출시의 진짜 큰 사건**입니다.

### 6/22까지가 결정적 — 무엇을 테스트할까

플랜 포함 무료 13일 창. 헤비유저라면 이 기간을 평소 안 하던 작업에 써야 합니다.

1. **장기 마이그레이션** — 평소 Opus 4.8로는 시도 안 해본 50만 줄+ 작업
2. **과학/연구 작업** — 논문 메타분석, 데이터셋 통합 등
3. **비전 + 코드 작업** — 디자인 시안 → 풀스택 구현
4. **다중 도구 오케스트레이션** — MCP 서버 여러 개 동시 사용

6/23 이후는 사용량 과금이라 비용 계산을 미리 해 두는 게 안전합니다.

## 실전 팁 — 6/22 무료 창에서 챙길 것

### 팁 1: 마이그레이션 한 번에 발사

Opus 4.8에서 나눠 했던 작업을 **단일 호흡**으로 시도. 컨텍스트 200K 이상이 일관성 향상에 도움.

### 팁 2: 데이터 보유 정책 명시

**Mythos 클래스는 30일 의무 보유**입니다 — Anthropic 정책. 기업 사용 시 컴플라이언스 팀과 사전 확인. 30일 후 자동 삭제(거의 대부분).

### 팁 3: 안전장치 회피 시도는 금지

생물/화학/사이버 카테고리 우회 시도가 감지되면 **계정 단위 제재** 가능성. 일반 보안 연구라면 Mythos 5 트러스티드 액세스 정식 신청.

### 팁 4: 6/22 비용 폭탄 예방

장기 작업 끝나면 **6/22까지 결과 저장** + 6/23 이후엔 일반 작업은 Opus 4.8로 회귀. Fable 5는 진짜 큰 작업에만.

### 팁 5: Mythos Preview 사용자는 자동 업그레이드 확인

[4/27 Mythos Preview](https://daily1bite.com/ko/blog/ai-tools/claude-mythos-preview-anthropic-glasswing-2026) 액세스 있던 분들 — 6/9 이후 Mythos 5로 자동 전환. **모델 ID와 가격 정책 변경 여부**를 발표 노트에서 다시 확인.
